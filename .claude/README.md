# AI development context

This directory keeps concise, version-controlled context for AI-assisted development.

Required files:

- `context.md`: architecture, module responsibilities, decisions, and integrations.
- `quick-ref.md`: setup, common commands, workflows, and troubleshooting.
- `README.md`: maintenance and security guidance for this directory.

Update these files whenever architecture, dependencies, commands, deck workflows, or project
conventions change. The team maintaining the repository is responsible for keeping the content
accurate.

Never include passwords, tokens, API keys, private keys, personal data, confidential deck content,
or credential-bearing URLs. Use placeholders or approved secret-manager references where a
configuration example requires a secret.
